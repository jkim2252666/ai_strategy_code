Data Analytics for Marketing & Business Strategy

A collection of R programming tutorials for business analytics, data science, machine learning, and statistical modeling.

About This Repository

This repository contains R programming tutorials developed for business analytics education. Each tutorial includes annotated R code, HTML outputs, and sample datasets to help students learn statistical analysis, machine learning, text analytics, and data visualization.

Tutorials

  • Linear Regression
  • Logistic Regression
  • Decision Tree
  • Random Forest
  • K-Means Clustering
  • Time Series Forecasting
  • Text Mining
  • Sentiment Analysis
  • Data Visualization (ggplot2)
